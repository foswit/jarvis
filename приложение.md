# Приложение «Джарвис»: твоя жизнь в одном приложении

## Идея
Одно приложение на телефоне. Внутри вкладка-чат, как Claude. Ты пишешь или диктуешь: «сегодня учил 40 минут flex», «идея: сайт для барбершопа», «запиши: позвонить риелтору в среду». Джарвис сам раскладывает это по местам: время, задачи, идеи, дневник, знания. Как CRM для бизнеса, только бизнес это ты.

## Главное открытие: это у тебя уже наполовину есть
В репозитории FullProg уже работают:
- приложение на телефоне (PWA, Next.js + Supabase), вход по паролю, пуш-уведомления
- ассистент в чате (`src/app/api/agent`, `src/server/ai.ts`, Claude через API)
- **действия ассистента**: он не только отвечает, но и записывает в данные (`src/domain/agentActions.ts`: записать время, взять квест, сдать квест, написать в дневник)
- дневник, статистика, наставник, недельный разбор

То есть «писать в чат, а он записывает данные» уже сделано, только для учёбы. Джарвис это FullProg, у которого действий больше, чем про учёбу.

## Рекомендация (выбрал по умолчанию): расширять FullProg, а не писать новое
Почему: готовая основа, ты её знаешь, ноль новой инфраструктуры. Новое приложение с нуля это месяц работы ради того, что уже есть.

## Что добавляем (по шагам, каждый маленький)
1. **Новые типы данных** рядом с квестами: `задачи`, `идеи`, `проекты`, `цели`. Это «таблицы» CRM.
2. **Новые действия ассистента**: `add_task`, `done_task`, `add_idea`, `add_note_to_project`, `set_goal`. Это по одной строке в `AgentAction` и в `applyAction` по образцу существующих.
3. **Вкладка «Джарвис»** на весь экран: чат наверху, быстрые кнопки «задача / идея / запись».
4. **Экраны-списки**: Задачи, Идеи, Проекты (простые списки, без наворотов).
5. **Связь с мозгом (этот репозиторий)**: раз в день приложение сохраняет итоги в `дневник/`, а ассистент читает `цели.md` и `знания/`, чтобы отвечать с контекстом.
6. **Обучение на себе**: после рабочей сессии Джарвис сам предлагает запись в `знания/` или `референсы/`, ты жмёшь «да».

## Чего НЕ делаем сейчас
- Telegram-бот: тебе он не нужен, если есть своё приложение с чатом на телефоне. Вернёмся, только если захочешь быстрые заметки без открытия приложения.
- Автономные «сам всё решает» агенты: сначала ручное подтверждение действий, потом доверие.
- Лишние виджеты ради эффекта.

## Как делаем (по твоему правилу)
planner разбивает шаги → ты пишешь код шага (я объясняю идею и даю пример) → reviewer → tester. Первый шаг на пробу: добавить действие `add_idea`, это ~30 строк по образцу `write_journal`.

## Вопрос к тебе
Первый шаг начинаем так: (А) я прошу planner расписать шаги 1–2 и ты пишешь `add_idea` сам, или (Б) я сразу сделаю шаги 1–4 в draft PR, а ты проверишь? Рекомендую А, это твой учебный проект.
