# Telegram-бот «Джарвис»: пульт от твоей жизни

Что это: бот в Telegram, который работает на твоём компьютере. Ты пишешь ему с телефона, он записывает в твой «мозг» (репозиторий jarvis), отвечает через Claude и по твоей кнопке «Да» запускает разрешённые команды.

## Что бот умеет

| Ты пишешь | Что происходит |
|---|---|
| `сегодня учил grid 40 минут` (любой текст) | запись попадает в `входящие.md` и сохраняется в GitHub |
| `/сегодня` | показывает `задачи.md` |
| `/ask с чего начать неделю?` | Claude отвечает, зная твои цели и задачи |
| `/pc статус` | бот спрашивает «Выполнить?», после «Да» запускает команду из `commands.json` |
| `/code jarvis сделай...` | то же для Claude Code на компьютере. **Выключено по умолчанию** |

## А как же вакансии и отчёт в 8:00?
Это уже сделано отдельно: твой репозиторий **job-agent**. Он каждый день в 8:00 по Варшаве ищет вакансии под твои критерии и присылает отчёт в Telegram. Ему не нужен компьютер, он работает на серверах GitHub. Чтобы он заработал, пройди `MORNING.md` в job-agent (там три шага на сайте GitHub).
**Совет:** используй для обоих одного и того же бота. Тогда отчёт и разговор будут в одном чате.

## Установка по шагам

Нужен компьютер, который включён, когда ты хочешь им управлять, и Node.js 20+ (проверь: `node --version`).

**Шаг 1. Создай бота.** В Telegram найди `@BotFather` → `/newbot` → придумай имя → он пришлёт **токен** (длинная строка). Если бот у тебя уже есть для job-agent, возьми его токен.

**Шаг 2. Скачай мозг на компьютер.**
```
git clone https://github.com/foswit/jarvis
cd jarvis/bot
npm install
```

**Шаг 3. Узнай свой chat id.** Напиши своему боту любое слово. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` (вместо `<ТОКЕН>` вставь токен). Найди `"chat":{"id":123456789` — это число и есть твой chat id. Сам токен никому не показывай.

**Шаг 4. Заполни `.env`.** Скопируй `.env.example` в `.env`, впиши токен, chat id и ключ Anthropic (`console.anthropic.com` → API keys).

**Шаг 5. Запусти.**
```
npm start
```
Должно появиться «Джарвис слушает». Напиши боту `/help`.

**Шаг 6. Чтобы работал всегда.** Пока окно с `npm start` открыто, бот живёт. Закрыл окно, бот спит. Позже настроим автозапуск при включении компьютера (скажи, на какой ты системе: Windows или Mac).

## Безопасность (прочитай обязательно)
Бот может запускать программы на твоём компьютере, поэтому защита тут главное:
1. **Только ты.** Бот отвечает человеку с твоим chat id в личном чате. Остальным молчит. Токен утёк? В `@BotFather` → `/revoke`.
2. **Белый список.** `/pc` запускает только то, что написано в `commands.json`. Любой другой текст отклоняется. Запуск идёт без оболочки, поэтому приписка `; rm -rf` ничего не делает.
3. **Кнопка «Да».** Ничего не запускается без подтверждения, кнопка живёт 2 минуты и срабатывает один раз.
4. **`/code` выключен.** Это самая мощная вещь: Claude Code сможет менять файлы. Включай (`ENABLE_CODE=1`) только когда поймёшь, как это работает. Работает лишь в папках из списка в `src/index.js`.
5. Файл `.env` никогда не отправляй в GitHub (он уже в `.gitignore`).

## Управлять компьютером можно и без бота
В приложении Claude (где мы сейчас пишем) есть Remote Control: Claude запускается на твоём компьютере в нужной папке, а ты управляешь им с телефона. Для задач вроде «поправь код в проекте» это безопаснее и мощнее бота. Бот нужен для быстрых заметок и простых команд.
